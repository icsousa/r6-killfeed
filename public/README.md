# 📂 Public Assets Directory

This directory contains the static image assets used by the **R6 Kill Feed Generator**, primarily the operator icons and weapon silhouettes rendered in the application.

## 🗂️ Structure

* `icons/operators/` - Contains the transparent operator icons used in the selection grid and the kill feed display.
* `icons/weapons/` - Contains the weapon silhouettes corresponding to the operators' loadouts.
